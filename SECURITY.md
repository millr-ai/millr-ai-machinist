# Security

## Reporting a vulnerability

Email hello@millr.ai with "Security" in the subject line. Describe the problem, the version and the file it affects, and how to reproduce it. Please do not open a public issue for a vulnerability before it is fixed. Millr Inc. reads every report and replies by email.

## Supported versions

Fixes go into the latest release. Check that the problem is still in it before you report.

## Scope

Millr is a Claude skill and plugin: instructions, a page template and scripts that run inside your Claude conversation or your Claude Code session. Millr runs no server and receives nothing from you, so a report concerns the files in this repository, such as a part file or a review that could make the review page run script, or a script that reads or writes outside the files it is given.
