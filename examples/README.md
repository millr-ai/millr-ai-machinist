# Example parts

Five small machined parts for trying Millr, each a STEP file with no drawing. Millr made them for trying the skill; they are covered by the same license as the rest of this repository. Attach one in a Claude conversation and ask, for example, "Is this ready for a shop?"

- `agent_bracket.step`: a pocketed mounting bracket an AI CAD agent drew.
- `deep_pocket_block.step`: a block with one deep pocket.
- `drilled_riser_block.step`: a riser block with two through holes.
- `twin_pocket_block.step`: a block with two pockets side by side.
- `angled_port_block.step`: a block with one angled blind hole.
